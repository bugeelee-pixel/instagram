# 메디박스 인스타 콘텐츠 플래너

메디박스 약국이 사진형 인스타그램 게시물의 일정과 원고를 만드는 비공개 웹 도구입니다. 기간·게시 빈도·중점 주제·브랜드·특별 일정을 입력하면 날짜별 카드뉴스 문구, 캡션, 해시태그, 사진 가이드와 약사 검토 포인트를 생성합니다.

## 주요 기능

- 1주, 2주, 1개월 일정과 주 3회, 주 5회, 매일 게시 조합
- 건강정보·약국 이야기·브랜드·방문 안내를 섞은 콘텐츠 구성
- 게시물별 4~6장 카드 문구, 캡션, 해시태그, 사진 가이드
- 게시물 개별 재생성 및 항목별·전체 복사
- 브라우저에 최근 일정 최대 10개 저장
- 진단·치료 보장 표현을 제한하고 모든 게시물에 약사 검토 안내 표시

## 로컬 확인

Node.js 20 이상에서 `web` 폴더로 이동해 실행합니다.

```powershell
npm test
npm run build
npm run validate
```

AI 호출에는 서버 환경변수 `OPENAI_API_KEY`와 `OPENAI_MODEL`이 필요합니다. 예시는 `web/.dev.vars.example`을 참고하세요. API 키를 브라우저 코드나 저장소에 넣지 마세요.

## 배포

`npm run build`가 만든 `web/dist`가 배포 산출물입니다. 서비스는 반드시 비공개 접근으로 설정하고, 위 두 환경변수는 배포 서비스의 서버 비밀값으로 등록합니다.

생성된 건강정보는 초안입니다. 실제 게시 전 약사가 사실관계, 용량, 금기, 제품 표시사항을 검토해야 합니다.
