# 메디박스 SEO / GEO 최적화 가이드

대상 사이트: https://hello.medibox.my
업종: 리테일형(창고형) 약국 · 주요 고객: 지역 상권 주민

> SEO = 네이버·구글 검색 결과에 잘 노출되게 하는 것
> GEO = ChatGPT·Perplexity·구글 AI 요약 같은 AI가 "근처 저렴한 약국" 질문에 메디박스를 답으로 꼽게 하는 것

동네 손님 상대 매장은 **홈페이지보다 지도(플레이스) 노출이 매출에 훨씬 직접적**입니다.
그래서 아래 우선순위를 그대로 따라가는 것을 추천합니다.

---

## 1순위: 지도·플레이스 (가장 효과 큼, 무료)

- [ ] **네이버 스마트플레이스** 등록·정비 (smartplace.naver.com)
  - 업체명에 키워드 자연스럽게: `메디박스 창고형약국` (과도한 키워드 나열은 제재 대상)
  - 대표 키워드 5개: `창고형약국`, `{{지역}}약국`, `대형약국`, `영양제`, `{{역명}}약국`
  - 매장 사진 20장 이상(외관·내부 진열·주차장·계산대), 영업시간, 주차, 편의시설 전부 입력
  - 소식 탭에 인스타 게시물과 같은 내용을 주 1~2회 올리기
- [ ] **카카오맵** 장소 등록·정보 수정
- [ ] **구글 비즈니스 프로필** 등록 (구글 지도 + AI 검색에 반영)
- [ ] 세 곳 모두 **이름·주소·전화번호(NAP)를 글자 하나까지 동일하게** — AI와 검색엔진이 같은 가게로 인식하는 핵심 신호
- [ ] 영수증 리뷰·방문자 리뷰 유도 (계산대 QR 안내문). 리뷰에 "저렴", "창고형", "주차" 같은 표현이 쌓이면 키워드 노출과 AI 답변 모두에 유리

## 2순위: 홈페이지 기본 설정 (이 폴더의 파일)

| 파일 | 하는 일 | 넣는 곳 |
|---|---|---|
| `head-meta.html` | 검색 제목·설명, 카톡/SNS 공유 미리보기, 네이버·구글 소유 확인 | `<head>` 또는 빌더의 SEO 설정 |
| `jsonld-pharmacy.html` | "이곳은 약국, 주소·영업시간·전화는 이것" 을 기계가 읽게 함 | `<head>` 또는 헤더 코드 삽입 |
| `jsonld-faq.html` | 자주 묻는 질문 → AI 답변 인용용 | 홈페이지에 FAQ 섹션을 만들고 함께 삽입 |
| `robots.txt` | 네이버·다음·구글·AI 크롤러 수집 허용 | 사이트 최상위 (`/robots.txt`) |
| `llms.txt` | AI용 매장 요약 카드 | 사이트 최상위 (`/llms.txt`) |
| `sitemap.xml` | 페이지 목록 | 직접 만든 사이트만 (빌더는 자동 생성) |

모든 `{{ }}` 부분을 실제 정보로 바꾼 뒤 넣으세요.

- [ ] **네이버 서치어드바이저**(searchadvisor.naver.com)에 사이트 등록 → 소유 확인 → 사이트맵·robots.txt 제출
- [ ] **구글 서치콘솔**(search.google.com/search-console)도 동일하게
- [ ] 적용 후 확인: 구글 [리치 결과 테스트](https://search.google.com/test/rich-results)에 주소 넣어 오류 없는지 확인

## 3순위: 홈페이지 문구 (GEO 핵심)

AI는 **짧고 구체적인 사실 문장**을 인용합니다. 홈페이지 첫 화면에 아래처럼 한 문단을 넣으세요.

> 메디박스는 {{지역}} {{역명}} 인근에 있는 창고형 약국입니다. 일반의약품, 영양제, 건강기능식품, 생활건강용품 {{0,000}}여 종을 넓은 매장에서 직접 고를 수 있고, 상주 약사에게 복약 상담을 받을 수 있습니다. 영업시간은 {{…}}이며 주차는 {{…}}입니다.

- H1(가장 큰 제목)은 페이지에 하나만: `{{지역}} 창고형 약국 메디박스`
- 숫자·사실을 넣기: 취급 품목 수, 매장 평수, 주차 대수, 역에서 도보 몇 분
- "자주 묻는 질문" 섹션을 화면에 실제로 노출 (`jsonld-faq.html` 내용과 동일하게)
- 사진 파일명과 alt 텍스트에 설명 넣기: `medibox-warehouse-pharmacy-interior.jpg`, alt="메디박스 창고형 약국 매장 내부 영양제 진열대"
- 인스타그램 프로필 링크를 홈페이지로, 홈페이지 하단에 인스타·네이버 플레이스 링크

## 타깃 키워드 맵

| 검색 의도 | 키워드 예시 | 어디서 잡나 |
|---|---|---|
| 지역 + 약국 | `{{지역}} 약국`, `{{역명}} 약국`, `{{동}} 약국 추천` | 플레이스, 홈 제목 |
| 창고형 | `창고형 약국`, `{{지역}} 창고형 약국`, `대형 약국` | 플레이스 키워드, 홈 H1 |
| 가격 | `저렴한 약국`, `약 싸게 파는 곳`, `영양제 싸게 사는 곳` | 홈 문구, FAQ, 리뷰 |
| 상황 | `일요일 약국`, `늦게까지 하는 약국`, `주차 되는 약국` | 영업시간·주차 정보, FAQ |
| AI 질문형 | "{{지역}}에 창고형 약국 있어?", "근처에 영양제 싸게 파는 약국" | FAQ, llms.txt, 리뷰 |

## ⚠️ 약국 광고 시 주의 (게시 전 약사 확인 필수)

- **전문의약품은 일반인 대상 광고 금지**(약사법). 홈페이지·인스타에 전문의약품 이름이나 가격을 올리지 마세요.
- 일반의약품도 효능을 과장하거나 단정하는 표현 금지 ("100% 효과", "완치" 등).
- "**최저가**", "지역 최저" 같은 표현은 객관적 근거가 없으면 표시광고법 문제 소지가 있습니다. `합리적인 가격`, `창고형 대용량 가격` 정도가 안전합니다.
- 의약품은 온라인 판매가 금지되어 있으므로 홈페이지에 "구매하기"·주문 기능처럼 보이는 요소를 두지 마세요.
