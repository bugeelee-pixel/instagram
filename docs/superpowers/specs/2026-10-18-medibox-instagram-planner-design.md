# 메디박스 인스타 콘텐츠 플래너 설계

## 목적

메디박스 약국이 사진형 인스타그램 게시물을 꾸준히 운영할 수 있도록, AI가 게시 일정과 게시글 초안을 생성하는 비공개 웹 도구를 만든다. 사용자는 생성 결과를 검토하고 복사해 직접 이미지로 제작하고 인스타그램에 게시한다.

## 성공 기준

- 사용자가 1주, 2주 또는 1개월 분량의 게시 일정을 한 번에 생성할 수 있다.
- 지정한 게시 빈도와 기간에 맞는 날짜별 콘텐츠가 중복 없이 생성된다.
- 각 게시물에 카드뉴스 장별 문구, 캡션, 해시태그 및 준비할 사진 안내가 포함된다.
- 전체 결과 또는 개별 항목을 한 번에 복사할 수 있다.
- 모바일과 PC에서 모두 편하게 사용할 수 있다.
- 의료·건강 콘텐츠는 과장된 효능, 진단 및 치료 단정을 피하고 게시 전 약사 검토를 안내한다.

## 범위

### 포함

- 메디박스 약국 전용 비공개 웹 도구
- AI 기반 일정 및 문구 생성
- 기간, 게시 횟수, 중점 주제, 브랜드·제품 및 특별 일정 입력
- 달력형 일정 확인
- 게시물 상세 보기
- 전체 복사, 개별 복사 및 개별 재생성
- 브라우저 내 최근 생성 일정 최대 10개 저장·열기·삭제
- 서버 측 AI API 연동 및 비밀값 보관

### 제외

- 인스타그램 계정 연결 및 자동·예약 게시
- 카드뉴스 이미지 또는 영상 생성
- 여러 약국이나 여러 사용자 지원
- 고객 개인정보 저장
- 데이터베이스와 복잡한 회원 관리

## 사용자 흐름

1. 사용자가 생성 기간을 1주, 2주 또는 1개월로 선택한다.
2. 주당 게시 횟수를 3회, 5회 또는 매일로 선택한다.
3. 중점 주제를 방문 유도, 건강정보, 입점 브랜드 또는 골고루 중에서 선택한다.
4. 필요하면 포함할 브랜드·제품과 휴무·공휴일·계절 행사 등 특별 일정을 입력한다.
5. `일정 만들기`를 누른다.
6. AI가 날짜별 콘텐츠를 구조화된 형식으로 생성한다.
7. 시스템이 날짜 수, 중복, 필수 문구 및 응답 형식을 검사한다.
8. 사용자는 달력에서 날짜를 선택해 게시물 상세 내용을 확인한다.
9. 사용자는 전체 결과나 개별 문구를 복사하거나, 마음에 들지 않는 게시물만 다시 생성한다.
10. 생성 결과는 현재 브라우저에 최근 일정으로 저장된다.

## 입력 항목

- 생성 기간: 1주 / 2주 / 1개월
- 주당 게시 횟수: 3회 / 5회 / 매일
- 중점 주제: 방문 유도 / 건강정보 / 입점 브랜드 / 골고루
- 포함할 브랜드 또는 제품: 선택적 자유 입력
- 특별 일정: 선택적 자유 입력

약국명은 `메디박스 약국`으로 고정하고 기본 말투와 콘텐츠 원칙도 전용 설정으로 관리한다. 지역명, 주소, 운영시간은 선택 가능한 전용 설정값으로 두며, 값이 비어 있으면 생성 결과에서 해당 정보를 언급하지 않는다. 실제 정보는 배포 전 또는 배포 후 설정에서 입력할 수 있다.

## 생성 결과

각 게시물은 다음 필드를 가진다.

- 게시 날짜
- 게시물 제목
- 콘텐츠 유형
- 카드뉴스 4~6장의 장별 문구
- 인스타그램 캡션
- 해시태그
- 준비할 사진 안내
- 검토가 필요한 사실 또는 표현 표시

## 콘텐츠 생성 원칙

기본 콘텐츠 비율은 다음과 같다.

- 건강정보: 50%
- 약국·동네 이야기: 20%
- 브랜드·제품: 20%
- 방문 안내: 10%

중점 주제를 선택하면 비율을 조정하되, 제품 광고만 연속되지 않도록 한다. 제목과 핵심 주제의 반복을 피하고, 메디박스 이름과 지역명은 자연스럽게 사용한다. 문체는 일반 고객이 이해하기 쉬운 친근한 약사 말투로 유지한다.

의료·건강 표현에는 다음 안전 원칙을 적용한다.

- 효능 보장, 진단 및 치료 단정 금지
- 개인별 건강 상태나 복용약에 따라 달라지는 내용은 상담 권고
- 사실 확인이 필요한 내용은 별도 검토 표시
- 모든 생성 결과에 `게시 전 약사가 내용을 검토하세요` 안내 표시

## 화면 설계

### 전체 구조

- 상단: `메디박스 인스타 콘텐츠 플래너` 제목과 간단한 설명
- 입력 영역: 기간, 빈도, 중점 주제, 브랜드·제품 및 특별 일정
- 결과 영역: 날짜별 게시물이 표시되는 달력
- 상세 영역: 선택한 게시물의 카드뉴스 문구, 캡션, 해시태그 및 사진 안내
- 기록 영역: 최근 생성 일정 최대 10개

### 주요 동작

- `일정 만들기`
- `전체 복사`
- `이 게시물만 복사`
- 항목별 복사
- `이 게시물 다시 생성`
- 최근 일정 열기 및 삭제

### 시각 방향

- 화이트, 딥그린, 연한 민트를 중심으로 한 약국다운 전문적이고 깨끗한 인상
- 모바일 우선 반응형 화면
- 큰 버튼과 읽기 쉬운 본문
- 생성 중, 성공, 실패 상태를 분명하게 표시

## 기술 구조

- 비공개로 배포되는 반응형 웹 애플리케이션
- 브라우저는 입력, 일정 표시, 복사 및 최근 기록 관리를 담당한다.
- 서버는 AI API 호출을 담당하며 API 키를 비밀값으로 보관한다.
- 생성 요청은 구조화된 JSON 응답을 요구한다.
- 최근 일정은 브라우저 로컬 저장소에만 저장하며 최대 10개로 제한한다.
- 고객 개인정보와 민감한 건강정보는 입력하거나 저장하지 않는다.

## 오류 처리

- AI 응답이 비어 있거나 구조가 잘못되면 서버에서 한 번 자동 재시도한다.
- 재시도 후에도 실패하면 이해하기 쉬운 오류 문구와 재시도 버튼을 표시한다.
- 생성 결과의 날짜 중복, 필수 필드 누락 및 요청 게시물 수 불일치를 검사한다.
- 개별 재생성 시 나머지 일정은 그대로 유지한다.
- 브라우저 저장 공간 오류가 발생해도 생성 결과 확인과 복사는 가능하게 한다.

## 검증 계획

- 기간과 주당 빈도의 각 조합에서 정확한 게시물 수 확인
- 날짜 중복 및 기간 밖 날짜 생성 여부 확인
- 필수 결과 필드 누락 검사
- AI 응답 오류와 재시도 동작 확인
- 전체·개별 복사 버튼 확인
- 개별 재생성 시 다른 게시물이 유지되는지 확인
- 최근 일정 10개 저장, 열기 및 삭제 확인
- 휴대폰 및 PC 화면에서 레이아웃과 조작 확인
- 의료·건강 안전 안내가 모든 결과에 포함되는지 확인

## 초기 버전 이후의 후보 기능

초기 버전에는 포함하지 않지만 실제 사용 후 필요성이 확인되면 다음을 검토한다.

- 마음에 든 게시물 즐겨찾기
- 게시 완료 체크와 간단한 성과 기록
- 자주 쓰는 브랜드·제품 목록 관리
- 일정 내보내기
- 이미지 생성 및 인스타그램 예약 게시
